# Tamyr: Steppe of Ancestors (Тамыр: Степь Предков)

2.5D-экшен-рогалик на Godot 4.7 (Forward+). Мир собран из 3D-блоков, персонажи нарисованы 2D-спрайтами-билбордами, камера сверху под 40°, как в Hades.

Степь осквернила Мгла Кара-Тұман, и корни Байтерека гниют. Кайсар, хранитель рода, уходит из Стойбища Предков по тропе в корни. В пути ему помогают Дары шести духов степи, а Сандык рода хранит прокачку между походами.

## Как устроена игра

- **Стойбище Предков (Хаб).** Вечернее стойбище у родового костра.
  - **Оружейная.** 5 видов оружия: меч, копьё, щит, лук, перчатки. У каждого 3 аспекта-облика легендарных батыров. Оружие и аспекты открываются за Пепел Тамыра.
  - **Чучело батыра.** Манекен для проверки урона, показывает DPS.
  - **Сандык.** Вечная прокачка: Рефлексы Көкбөрі (заряды рывка, скорость атаки), Кровь Батыра (здоровье), Клятва Жизни (воскрешение), Тень Степи (урон в спину), Благословение Рода (редкие дары).
  - **Домбра у костра.** Сыграй кюй без ошибок, и он станет «Музыкальным зарядом» на следующий поход:
    - Адай — быстрее и дальше рывок;
    - Қорқыт — идеальное уклонение замедляет время;
    - Ақсақ құлан — быстрее бег;
    - Балбырауын — быстрее атаки;
    - Кеңес — больше урон.
  - **Сюжет.** Әже Ұлжан, Дух-Корень и кузнец Ұста ведут историю дальше после каждого похода: после смерти, после боссов и после финальной победы.
- **Поход.** 3 биома по 6 комнат и босс в конце каждого:
  1. Осквернённая степь, босс Жезтырнақ;
  2. Корни Байтерека, босс Шойынқұлақ;
  3. Чертог Ерлика, финальный босс — Первый хан.

  После зачистки комнаты появляется награда, затем 2 двери. Символ над аркой показывает, что ждёт за дверью: дар духа, Пепел, дирхемы, Камень Силы (улучшение дара), исцеление, Забытая нота (новый кюй), лавка Караванщика, «Спор Духов» или босс. Есть и особые комнаты:
  - элитные: враги с бронёй;
  - «Печать Номада»: испытание на время за дополнительную награду;
  - привал у родника;
  - лавка с Колодцем Обмена: в колодце можно продать дар.
- **Дары 6 духов.** Тенгри (молнии), Ай-Мерген (криты и стрелы), Умай (огонь), Жер-Су (камень, лёд, удары о стену), Ерлик (скверна и проклятия), Көкбөрі (кровотечение и ярость).
  - Дары занимают слоты «атака», «особая» и «рывок», остальные дары — пассивные.
  - Редкость: обычный, редкий, эпический. Уровни I–III.
- **Бой и акробатика.**
  - Рывок с неуязвимостью. Рывок сквозь атаку врага — идеальное уклонение.
  - Бег по стене, отскок от стены и сразу особая атака: удар сверху, ×2.5 по броне.
  - Зацеп за уступ, подкат под широкие удары, перелёт через врага.
  - У элитных врагов есть броня. Её ломают тяжёлые удары. Отброшенный враг получает урон об стены и при падении с ярусов.
  - Каждая опасная атака врага заранее подсвечивается красной зоной.
- **Смерть.** Клятва Жизни воскрешает героя прямо в комнате. Если зарядов Клятвы нет, герой возвращается в Хаб. Пепел и открытия сохраняются, дирхемы и дары пропадают.

## Управление

| Действие | Клавиатура и мышь | Геймпад |
|---|---|---|
| Бег | W A S D / стрелки (относительно камеры) | левый стик / крестовина |
| Прицел | курсор мыши | направление стика / движения |
| Прыжок, отскок от стены | Пробел | A |
| Рывок | Shift | B |
| Подкат | C / Ctrl | RB |
| Обычная атака | ЛКМ / J | X |
| Особая атака | ПКМ / K | Y |
| Действие (двери, тотемы, NPC, домбра) | E | LB |
| Список даров | Tab | Back |
| Пауза | Esc | Start |
| Диалог: дальше | E / ЛКМ / Enter / Пробел | A |
| Выбор дара | мышь / 1–3 / Enter | крестовина + A |
| Домбра: лад | мышь (радиальное меню) / 1–6 | левый стик |
| Домбра: удар вниз / вверх | ЛКМ / ПКМ | X / Y |
| Домбра: тремоло | СКМ / Пробел | — |

## Как запустить

Открыть папку в Godot 4.7 и нажать F5. Из терминала:

```bash
godot --path .            # главное меню (game/scenes/title.tscn)
```

## Проверки

```bash
godot --headless --path . --import                      # один раз после клонирования
godot --headless --path . res://tools/check.tscn        # загрузка всех скриптов и сцен → "CHECK DONE, failed: 0"

# авто-тесты модулей и стыков (код выхода 0 — всё прошло)
godot --headless --path . res://tools/tests/player_test.tscn         # герой, камера, HUD, диалоги
godot --headless --path . res://tools/tests/boons_weapons_test.tscn  # оружие × аспекты, дары, окно выбора, тотем
godot --headless --path . res://tools/tests/enemies_test.tscn        # враги, броня, статусы, боссы
godot --headless --path . res://tools/tests/rooms_test.tscn          # планировщик, арены, все типы комнат
godot --headless --path . res://tools/tests/hub_test.tscn            # Хаб, оружейная, Сандык, домбра, сюжет
godot --headless --path . res://tools/tests/integration_test.tscn    # стыки: ввод→оружие→враг→HUD, дары↔Bus, кюи, смерть→Хаб
godot --headless --path . res://tools/tests/full_run_test.tscn       # полный поход: 21 комната, 3 босса, победа → Хаб
#   ... full_run_test.tscn -- fast   # то же, но ускоренно: к комнате перед боссом

# smoke: сцена N секунд, в выводе не должно быть ERROR / SCRIPT ERROR
godot --headless --path . res://tools/smoke.tscn -- scene=res://game/scenes/title.tscn secs=4
godot --headless --path . res://tools/smoke.tscn -- scene=res://game/hub/hub.tscn secs=8
godot --headless --path . res://tools/smoke.tscn -- run secs=120 bot god   # бот: бой → награда → дверь, несколько комнат
godot --headless --path . res://tools/smoke.tscn -- run secs=240 bot       # без бессмертия: смерть → Хаб
```

Скриншоты снимаются через xvfb, рендер opengl3:

```bash
xvfb-run -a godot --path . --rendering-driver opengl3 res://tools/tests/hub_shot.tscn   -- out=/tmp/shots
xvfb-run -a godot --path . --rendering-driver opengl3 res://tools/tests/rooms_shot.tscn -- out=/tmp/shots room=boss biome=1
xvfb-run -a godot --path . --rendering-driver opengl3 res://tools/tests/player_shot.tscn -- out=/tmp/shots
```

При выходе из headless-прогонов Godot иногда пишет `resources still in use at exit` / `ObjectDB leaked`. Это звуки, которые ещё играли в момент `quit()`. На игру это не влияет.

## Структура

| Папка | Что внутри |
|---|---|
| `game/ARCHITECTURE.md` | контракты модулей: группы, сигналы, API |
| `game/core/` | автозагрузки `Bus` (сигналы), `Meta` (сохранение), `Run` (поход), `Sfx`, а также `Hit` и `Combat` |
| `game/player/` | герой (`Player`): движение, рывок, акробатика; камера (`GameCamera`); песочница |
| `game/ui/` | HUD, пауза, экран смерти, числа урона, `DialogueBox`, общий `UiKit` |
| `game/weapons/` | 5 видов оружия × 3 аспекта, фабрика, данные оружейной, модели и снаряды |
| `game/boons/` | данные даров (`BoonData`), `BoonManager`, окно выбора `BoonChoice`, тотем духа |
| `game/enemies/` | `EnemyBase`, 6 врагов, 3 босса, телеграфы, снаряды, фабрика, данные |
| `game/rooms/` | комната, планировщик похода, 8 шаблонов арен, волны, двери, лавка, Печать Номада, награды |
| `game/hub/` | Стойбище Предков: оружейная, манекен, Сандык, домбра и кюи, NPC и сюжет (`Story`) |
| `game/fx/` | общие эффекты `Fx3D`: искры, кольца, молнии, телеграфы |
| `game/scenes/` | главное меню `title.tscn` |
| `assets/` | спрайты (`SpriteFrames`), фоны, UI, звуки и музыка |
| `tools/` | `check.tscn`, `smoke.tscn` (с ботом), `tests/` (авто-тесты и скриншоты), генераторы ассетов и звука |
| `art_src/`, `preview/` | исходники арта и промпты, демо эффектов |
| `legacy_2d/` | старая 2D-версия («Батыр: Священная Юрта»), в игре не используется |

Арт сгенерирован локально ([tools/codex_image.py](tools/codex_image.py)) и нарезан скриптом [tools/build_assets.py](tools/build_assets.py). Звуки синтезированы кодом: [tools/make_audio.py](tools/make_audio.py) и [tools/make_dombra.py](tools/make_dombra.py) (струны домбры, Karplus-Strong).

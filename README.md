# Батыр: Священная Юрта

2.5D-сайдскроллер на Godot 4.7: казахская степь, хаб-юрта, волны врагов, Дары богов и вечная прокачка.

## Как запустить

Открыть папку в Godot 4.7 и нажать F5, или из терминала:

```bash
/Applications/Godot.app/Contents/MacOS/Godot --path /Users/boozybats/Public/Repos/Alisher-game
```

## Управление

| Клавиша | Действие |
|---|---|
| A / D, ← / → | бег |
| J, левая кнопка мыши | удар; три подряд — комбо, третий тяжёлый и пробивает броню |
| Shift, Пробел | кувырок: неуязвимость, перезарядка 1 с |
| J во время кувырка | рывок-удар насквозь |
| K, правая кнопка мыши | щит в любой момент и в любую сторону, как в Dead Cells: нажатие ставит его на 0.5 с, зажатый держится; прерывает удар, кувырок, рывок и оглушение; с направлением — туда, без направления — к атакующему врагу; −75% урона; даже самое короткое нажатие засчитывается, а нажатие чуть раньше конца перезарядки срабатывает, как только щит готов; щит ничего не принял — перезарядка 0.6 с, принял удар — можно ставить сразу снова |
| удар в первые 0.2 с щита | идеальный блок: урона нет, враг оглушён и получает ×1.5 урона |
| «!» над врагом | враг замахивается: жёлтый — удар можно блокировать, красный — только кувырок |
| E | взаимодействовать в юрте |
| Esc | пауза |

Поддерживается геймпад.

## Как устроена игра

- **Юрта (хаб).** Сундук «Алтын Сандық» — вечная прокачка за асыки. Очаг От-Ана — статистика и подношения перед вылазкой: стартовый Дар или Тұмар, который один раз спасает от смерти. Дверь справа — выход в степь.
- **Забег.** Две стадии по три волны:
  1. «Степной Курган», закат: две волны, затем мини-босс Жезтырнак.
  2. «Сердце Кургана», ночь: две волны, затем финальный босс Шойынқұлақ.

  После каждой волны — выбор Дара одного из трёх богов (Тенгри, Умай, От-Ана) в ромбы «Удар сабли / Рывок / Щит». Когда ромбы заполнены, Дары усиливаются до III уровня. Победа даёт следующий, более тяжёлый круг. Смерть возвращает в юрту; асыки сохраняются.
- **Враги:**
  - балбал: тяжёлый удар, броня, двойной удар;
  - дух степи: бросок;
  - чёрный волк: быстрый, прыжок и укус;
  - аруақ-мерген: стреляет; идеально отбитая стрела летит обратно;
  - бақсы: самонаводящиеся шары, телепорт, призыв духов.

  Все удары и тайминги лежат в данных: [scripts/data/enemy_db.gd](scripts/data/enemy_db.gd). Волны — в [scripts/data/waves.gd](scripts/data/waves.gd).

## Арт и звук

- Персонажи, фоны и интерфейс сгенерированы локальным Codex ([tools/codex_image.py](tools/codex_image.py), [tools/codex_batch.py](tools/codex_batch.py)). Промпты — в `art_src/prompts`, исходные листы — в `art_src`.
- [tools/build_assets.py](tools/build_assets.py) режет листы в `assets/`: убирает пурпурный фон, выравнивает кадры и пишет `SpriteFrames` с длительностями кадров (удержание ключевых поз).
- Звуки и музыка синтезированы кодом: [tools/make_audio.py](tools/make_audio.py) — домбра, кобыз, дауылпаз.
- Живость при 4 кадрах на анимацию дают приёмы из [preview/fx_demo.html](preview/fx_demo.html):
  - хитстоп, тряска камеры;
  - сжатие и растяжение спрайта;
  - шлейфы;
  - процедурная лента;
  - «кипение» линий мира на 8 fps;
  - ветер, жара, частицы.
